# Mygiruwo

## What is this project

**My gigantic rust workspace (*Mygiruwo*)** is a workspace where I'd like to have multiple rust packages that can interop with each other without having to use rust Crates.io as I don't want the headache of maintaining those crates, and I like that it's all in one git repo :).

Of course, having all the package in a single workspace + directory means I have to set rules on how to manage those.  
So please, check the [PROJECT-LAYOUT.md](./docs/PROJECT-LAYOUT.md) file that describe how the project is / while be structured.
